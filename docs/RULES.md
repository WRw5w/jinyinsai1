## 约束与交付

| 项目 | 复赛口径 |
|---|---|
| 辊道 | 50–150 m，宽 2 m，承重 60 t |
| 冷床轮数 | 每个组合方案最多 6 轮 |
| 组合 | 同钢种、同规格；同一订单不可跨方案，orders 列表不得重复 |
| 连续性 | 同一订单跨轮时相邻连续，不能插入其他订单、不能跳轮；实现语义见 [证据](EVIDENCE.md) |
| 物料 | 每轮钢坯重不低于棒材重；每订单分配重量不低于需求；定尺整数倍 |
| 覆盖 | 除异常订单外，所有订单参与计算 |
| 切损 | 每端 1 m、每轮共 2 m；length_scheme 写净长度 |
| 并排长度 | 每根棒材上的分配长度；质量乘并排根数，刀数不乘根数 |
| 计刀结构 | 每轮总段数 +1；浮点取整的实际平台口径仍待复赛小分校准 |
| 超产 | 无已声明的超产上限；按复赛答疑，超产不增加成材率分子 |
| 有效组合 | 采用后续答疑的“同轮至少两个订单”口径；不能仅凭在同一方案内就计入 |
| 异常输入 | B20270281 原始重量 -25.418 t，现行预处理隔离，不能虚构补值；保留审计 |

条款 6 原文：“同一订单若分在多轮冷床上锯切，其必须在相邻轮次中连续锯切，中间不得插入其他订单，也不得跳轮次锯切”。

## 已修订与仍未定案

- **不恢复 10 秒硬时限**：9 月 21 日赛题组答疑明确废止；不要仅因旧 PDF 仍写该条而重新限制搜索。
- 基准刀数采用 **160000**（9 月 21 日 15:46 答疑）；不是 PDF 明示，也不是毫无来源的猜测。
- `40/30/20/10` 与时间权重并入成材率后的 `40/40/20` 保留为对照口径；复赛尚未完成实测校准。
- 每次违规扣 5 分与现有反馈一致；正分预测须先满足约束。
- 取整、子分舍入/封顶、成材率直径取整模型均应带阶段和实测依据，不能把初赛校准当复赛认证。

## 提交要求

每天最多 5 次，取复赛最高分；结果截止 2026-10-05 20:00，代码截止 2026-10-07 23:59（Asia/Shanghai）。
结果 ZIP 根目录仅放 `复赛结果_团队名.json`；作品另交完整代码、README、至少 3000 字 PDF 技术报告和可复现实现。
最终代码须在 Linux 测试通过，Python 为主或胶水语言；商业求解器仅限 COPT。
当前模型无法保证获得 60 分授奖基线，现有 90+ 预测不可用于作此保证。
