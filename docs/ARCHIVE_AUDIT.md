# 档案信息密度评估与整理验收

日期：2026-09-26。范围：复赛求解分支及 new_mcp 迁移档案。
基线：求解器 `3995781`；MCP `40fae38`（整理时重新读取远端，未覆盖其新修复）。

## 判断依据

信息密度偏低不是按压缩率猜测，而是发现入口的职责失配：

- README 与 HANDOFF 开头仍大量讨论初赛候选，四个入口共 1663 行 / 130734 B。
- 70 份 Markdown 共 5956 行 / 459035 B；八份事件记忆共 132692 B，而 docs 现行专题层不存在。
- 条款 6 出现“已定案→未决→旋转无效→排序已确定”的连续撤回；新规则报告又恢复已废止的 10 秒限制。
- 迁移指南要求先读约 1.6 万行对话，旧的三岛未完成状态与新提交记载不一致。

字节数不是“有用信息百分比”；这里用入口体量、错误现行判断、重复与过期待办作为判断依据。

## 采取的处理

| 类别 | 处理 |
|---|---|
| 现行任务 | README + CURRENT；按任务进入 RULES、EVIDENCE、PLAN、RUNBOOK、MIGRATION |
| 失效结论、初赛过程、旧每日记忆 | 完整压缩；原路径留短指针，不能当现行指令 |
| 已被后续进度覆盖的迁移/任务状态 | 改为先核对恢复后的实际文件，不自动重跑 |
| 原始约束、PDF、平台 JSON、提交 ZIP、源码与数据 | 原路径、原字节保留，作为证据和回归输入 |
| 密钥、原始会话、浏览器状态 | 未公开、未重新打包；原加密归档不变 |

## 验收与边界

两个 ZIP 均通过 CRC 与逐项 SHA-256 回读检查；复赛提交包/源码等既有非 Markdown 文件未修改。
新入口本地 Markdown 链接无断链。旧文档均有逐文件分类清单，不删除唯一原始证据。
Windows 缺少符号链接权限，AGENTS.md 仅引用唯一规则源 CLAUDE.md，不维护第二份规则正文。
旧初赛 main、原 nolimit 工作目录及原 MCP 工作目录未覆盖；修改在独立 worktree 和分支，避免夹带未提交文件。
本次没有实现求解器或 MCP 服务修复、运行搜索、访问登录浏览器、提交比赛或创建监控任务。
唯一工具适配：迁移打包器改为从压缩包校验并读取完整可读会话，避免误打包导航短页。
